# Reporting security issues

Do not publish credentials, student details, private recordings or live exploitation steps in an issue. Use GitHub's private vulnerability reporting when enabled. If unavailable, open an issue asking maintainers for a private contact route without describing sensitive details.

Keep dependencies current, store service credentials outside Git and frontend builds, and run production behind HTTPS. The public lesson collection intentionally needs no login; verified Google identity protects account backups and AI usage. The MIT license and contribution guide do not grant access to other services or accounts.
